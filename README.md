# AGROTRIAL – Sistema de Gestión Financiera y Contabilidad

Sistema web para el control de ingresos, egresos, gastos fijos y rentabilidad de la empresa AGROTRIAL.

## 🚀 Acceso en Línea
👉 **[https://desfaze.github.io/agrotrial-finanzas/](https://desfaze.github.io/agrotrial-finanzas/)**

## 👥 Roles
- **👑 Dueño / Dirección:** Dashboard directivo, rentabilidad neta y reportes estratégicos.
- **✍️ Operador de Carga:** Registro de ingresos, egresos y gastos fijos mensuales.
- **🛡️ Administrador:** Gestión de usuarios y control total.
