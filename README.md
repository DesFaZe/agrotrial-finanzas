# AGROTRIAL – Sistema de Gestión Financiera y Contabilidad

Sistema web para el control de ingresos, egresos, gastos fijos y rentabilidad de AGROTRIAL.

## Acceso
[https://desfaze.github.io/agrotrial-finanzas/](https://desfaze.github.io/agrotrial-finanzas/)

Las credenciales las asigna el administrador. El login no muestra usuarios ni contraseñas.

## Roles
- **Administración:** dashboard, rentabilidad y reportes.
- **Contabilidad de Carga:** registro de ingresos, egresos y gastos fijos.
- **Admin:** acceso total, usuarios y bandeja de sugerencias.

No se puede cambiar de rol desde la interfaz: hay que cerrar sesión e ingresar con otra cuenta.

## Datos
Los registros se guardan en **IndexedDB** del navegador. Para copiarlos a otro dispositivo, usá el respaldo JSON.
