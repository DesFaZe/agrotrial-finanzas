# AGROTRIAL – Finanzas

## Repositorio
- Remoto: `https://github.com/DesFaZe/agrotrial-finanzas.git`
- Rama: `main`

```powershell
git push -u origin main
```

## GitHub Pages
1. Repo → Settings → Pages
2. Branch `main`, folder `/ (root)`
3. URL: `https://desfaze.github.io/agrotrial-finanzas/`

## Roles
El administrador crea usuarios y asigna el rol. Cada cuenta entra solo a su interfaz. Para usar otro rol hay que cerrar sesión.

Las sugerencias las recepciona únicamente el admin.

## Base de datos
IndexedDB en el navegador. Respaldo y restauración JSON desde el botón de base de datos en la barra superior.
